# fund-analyzer · 基金与行业分析工具箱

输入基金代码，输出**行业现状 + 涨跌趋势预测 + 当日买卖建议**，一键生成离线 HTML 报告。
所有数据来自公开接口（天天基金、东方财富、同花顺、腾讯行情），无需任何 API Key 或账号。

---

## 一、三分钟上手

### 1）准备环境

需要 **Python 3.10 及以上**（代码用了 3.10+ 的类型语法）。检查版本：

```bash
python --version        # Windows
python3 --version       # macOS / Linux
```

安装依赖（约 1~3 分钟）：

```bash
pip install -r requirements.txt
```

> 如果本机同时有 Python 3.8 之类旧版本，请用 `python3.11 -m pip install ...` 明确指定版本，
> 运行时也用同一个解释器，例如 `python3.11 fund.py diag 016371`。

### 2）跑第一条命令

```bash
python fund.py diag 016371
```

约 2~3 分钟后，会在 `output/` 下生成 `基金诊断报告_xxx016371.html`，双击即可用浏览器打开。

### 3）Windows 用户

直接双击 **`run.bat`**（自动装依赖 → 查看清单 → 跑追踪）。
macOS / Linux 用户执行 `bash run.sh`。

## 二、命令一览

| 命令 | 作用 | 耗时 |
|---|---|---|
| `python fund.py diag 016371` | 单只基金诊断（行业归因 + 趋势 + 预测 + 买卖建议） | 2~3 分钟/只 |
| `python fund.py diag 016371,024593` | 多只批量诊断 | 累加 |
| `python fund.py watch add 011453` | 把基金加入每日追踪清单 | 秒 |
| `python fund.py watch list` / `rm 011453` | 查看 / 移出清单 | 秒 |
| `python fund.py track` | 按清单批量诊断 + 留痕 + 生成决策面板 | 约 3 分钟/只 |
| `python fund.py panel` | 只用已保存结果重渲染面板（刷新时点提示） | 秒 |
| `python fund.py report` | 行业 / ETF 全景报告（40 个行业 + 基金 + ETF） | 5~10 分钟 |

常用参数：`--dir 输出目录`（默认 `./output`）、`--bench 沪深300`（对比基准）、`--start 20230101`（数据起点）。

**运行时间建议**：场外基金 15:00 前申赎按当日净值确认，所以**每天 14:30~15:00 之间跑最有价值**；
15:00 之后跑，报告里会明确标注"已过当日决策窗口"。

## 三、输出了什么

```
output/
├── 基金诊断报告_名称代码.html     单只基金完整诊断（含净值曲线、行业暴露、预测分布）
├── 基金行业ETF分析报告.html       行业全景报告（report 命令）
├── 决策面板_YYYYMMDD_HHMM.html    当日多只基金的决策总览
├── 最新决策面板.html              上面那个的最新版本（固定文件名，方便收藏）
├── daily/YYYY-MM-DD/*.json        每日留痕，可回溯某天当时说了什么
├── history.csv                    历史评分与档位轨迹
└── diag_代码.json                 诊断原始数据，可供二次分析
```

报告里的核心结论：

- **评分与档位**：买入 / 偏多 / 持有 / 减仓 / 卖出，附建议仓位百分比
- **止损 / 止盈参考位**，以及**失效条件**（什么情况说明判断错了）
- **行业暴露**：持仓穿透到个股 → 映射行业，看清基金到底在押什么
- **未来 20 / 60 日收益分布**：历史类比法给出上涨概率、中位数、悲观 P5、乐观 P95

## 五、常见问题

**Q：报 `缺模块 akshare / pandas`？**
依赖没装成功。执行 `python -m pip install -r requirements.txt`，注意用**运行脚本时的同一个 python**。

**Q：跑一半报 `接口返回为空 / SSL error / 403`？**
数据源（东财、同花顺）有限流。代码内置熔断与多源回退，偶发失败会自动重试其他源；
若连续失败，等 5~10 分钟再跑即可。

**Q：报告打开是空白 / 图不出来？**
图表库已内联在 HTML 里，不联网也能看。若仍空白，换 Chrome / Edge 打开，不要用系统自带的旧 IE 内核。

**Q：Windows 控制台中文乱码？**
`fund.py` 已自动设置 UTF-8；若还乱码，在命令行先执行 `chcp 65001`。`run.bat` 已内置这一行。

**Q：报告里的数字和我 App 上看到的不一样？**
场外基金净值一般晚上 20:00 后才更新，盘中跑会用上一交易日净值 + 实时行业数据估算，
报告里会标注"净值截止日期"。另外持仓用的是**最新季报**（滞后），个股已调仓的话归因会有偏差。

**Q：能改输出目录吗？**
`--dir D:\我的分析` 即可，或设环境变量 `FUND_OUT`。

## 六、重要声明

本工具输出的是**基于公开数据的量化信号推演**，包括评分、档位、概率分布，均为统计意义上的参考，
**不构成任何投资建议**。历史类比不能预测未来，概率 60% 也意味着 40% 会反向。
据此操作，盈亏自负。

数据版权归各数据源所有，请仅用于个人研究，勿用于商业分发。
